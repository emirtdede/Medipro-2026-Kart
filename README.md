# English Version

An interactive, premium, and visually stunning web-based New Year greeting card designed specifically for the **Medipro Family** to celebrate the upcoming year of **2026**. The web app features a beautiful holiday theme, custom messages, and transitions seamlessly into an immersive full-screen celebration video.

## 🚀 Key Features

*   **❄️ Canvas-based Snowfall Effect**: A smooth, real-time, hardware-accelerated snowfall animation rendered using HTML5 Canvas API.
*   **📱 Interactive Slide Cards**: A glassmorphic card interface featuring 5 distinct slide panels to display custom messages of gratitude, accomplishments, and future wishes.
*   **🌟 Twinkling Neon Christmas Tree**: An animated vector Christmas tree adorned with colorful, sparkling neon lights that dynamically change HSL values.
*   **🎬 Immersive Full-Screen Video**: Upon reaching the last slide, the card triggers a cinematic full-screen video overlay (`newyear.mp4`) with smooth CSS transitions.
*   **Touch Swipe & Keyboard Navigation**: Fully supports touch swipe gestures for mobile screens and automatic reveal animations.
*   **⚡ Premium Performance**: Optimized animations built using `requestAnimationFrame`, transitions using `will-change` properties, and responsive layout styling (`viewport-fit=cover`).

## 🛠️ Installation & Execution

Since the project is built entirely on client-side vanilla technologies, it does not require any build tools or package managers.

### 1. Clone the Repository
```bash
git clone https://github.com/emirtdede/Medipro-2026-Kart.git
cd Medipro-2026-Kart
```

### 2. Run Locally
You can run this project locally by double-clicking on `index.html` or running a simple local development server:
```bash
# Python 3
python -m http.server 8000

# Node.js (npx)
npx serve .
```
Open `http://localhost:8000` or the corresponding address in your browser.

# Türkçe Versiyon

**Medipro Ailesi** için özel olarak tasarlanmış, **2026** yılına geçişi kutlayan, modern arayüze ve etkileşimli geçiş efektlerine sahip web tabanlı bir yeni yıl tebrik kartıdır. Ziyaretçilere görsel bir şölen sunan uygulama, kart mesajlarının sonunda tam ekran video gösterimi ile tamamlanır.

## 🚀 Öne Çıkan Özellikler

*   **❄️ Canvas Tabanlı Kar Efekti**: Tarayıcıyı yormayan, donanım hızlandırmalı ve gerçek zamanlı çalışan HTML5 Canvas kar yağışı animasyonu.
*   **📱 Etkileşimli Kart Geçişleri (Glassmorphism)**: 5 sayfadan oluşan, Medipro ailesine teşekkür, birliktelik ve yeni yıl dilekleri içeren modern slayt yapısı.
*   **🌟 Işıl Işıl Parlayan Yılbaşı Ağacı**: HSL renk paletinde dinamik olarak renk değiştiren ve parıldayan neon ışıklı animasyonlu yılbaşı ağacı.
*   **🎬 Tam Ekran Video Deneyimi**: Slaytların sonuna ulaşıldığında, yumuşak bir kayma efektiyle tam ekran video katmanına (`newyear.mp4`) geçiş yapılır.
*   **Dokunmatik Ekran & Kaydırma Desteği**: Mobil cihazlar için optimize edilmiş kaydırma (swipe) jest desteği ve animasyonlar.
*   **⚡ Yüksek Performans**: `requestAnimationFrame` kullanımı, `will-change` optimizasyonları ve mobil cihaz çentik alanları uyumluluğu (`viewport-fit=cover`).
